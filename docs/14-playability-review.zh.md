# 可玩性评审：v0.1.0（2026-11-18）

**覆盖范围**
- 浏览器里用离线 Grandma 从头玩了一局 Easy（跳过教程）。
- 通过 API 按"聪明玩家"的问法各玩了 Easy、Medium 2、Hard 一局。
- 跑了 `npm run eval:probe`，8 道题 × 12 次。
- 读了真实模型 Haiku 5.5 的 736 轮评测原文（`eval/results/2026-11-18-07-38-…`），以及第 44、57–61 轮的独立评审。

**没覆盖**
- 真人玩家。
- 真实模型下的整局对话：评测每个问题都是新开一局问的。
- 声音的实际听感。
- 手机实机。

## 结论

工程、公平性和操作已经很扎实（三位独立评审 7.0–7.3 分，0 泄露）。**现在拖累乐趣的不是 bug，而是挑战太小、玩法太单一。**

- **太快就解开了。** 聪明玩家解一题只要 2–5 个问题，而茶、打盹、饼干、Uncle Michael 的提示、星级都是按 7–16 个问题设计的。所以这些资源系统在正常游玩中从不起作用，没有紧张感。
- **8 道题是同一个套路。** 都是"一个名字 + 一个年份"，年份只差一步加减法。玩过两道就摸清套路了，之后的"aha"都一样。
- **房间可有可无。** 不看房间里任何物品也能解开 Easy。
- **"套奶奶的话"这个卖点还没有变成玩法。** 她有问必答，没有需要说服、需要拿东西提醒她的时候。
- **真实模型 Grandma 的口头禅太重复。** 78% 的回答以 "Oh, for heaven's sake" 开头。

## 优化方案

按"乐趣提升 ÷ 工作量"排序。标【团队决定】的会改谜题内容，要团队先批准。

### 阶段 1：让她更好聊，不改谜题（S，纯代码）——已完成代码部分（第 66 轮），真实模型评测待跑

1. **开头轮换**：每次访问记录她用过的开头和口头禅，下一次请求带上"别再用这些开头"；"sweetheart"每 3 句最多出现 1 次。
2. **回答更短**：问答类目标 25–40 词，讲故事或看物品时可以更长。
3. **离线版闲聊**：不再用本题链路上的记忆（修 P10），约四成改用 47 条彩蛋，其余仍是别的记忆，保留"干草堆"的干扰作用。
4. **教程减到 3 步**，其余改为第一次用到时的一次性提示。

**退出检查**：
- 用真实模型跑一次评测（约 $0.15，需要你批准），同一开头占比 ≤ 20%，回答中位数 ≤ 40 词，泄露仍为 0；
- 离线探针中，闲聊不再带出链路事实。

### 阶段 2：让房间和"套话"成为必需（M）【团队决定】

1. **"看到才想起来"的记忆**：数据里给某些事实标 `needs_object`。她只有在看到对应物品后才会完整讲出来，之前只给模糊的指向，比如"有张照片的…在相册里吧？"。这是代码里的规则，模型只负责措辞。
2. 每道 Medium/Hard 至少一格走这条路（例如 Hard 的 Michael 出生年要看出生通知卡，Medium 2 的三块钱要看蓝丝带）。
3. 修 P4：2 道 Medium 的名字部分也绕一步。

**退出检查**：
- 探针 0/8 道题能被直接提问解开；
- 新测试"不看物品解 Medium/Hard"失败；
- AI 玩家的问题数落在 Easy 4–8、Medium 7–12、Hard 10–16。

### 阶段 3：更多推理方式（M）【团队决定】

在现有 44 条事实上写 3–4 道新便条，每道用一种新的推理方式：

| 新推理方式 | 例子 | 好玩在哪里 |
|---|---|---|
| **她记错，证据纠正** | 她坚持"婚礼在 1962 年"，但结婚照背面和教堂请柬都写着另一年。数据里明确标出这是固定的"记错"，属于既定事实，不是模型编的。 | 玩家第一次要质疑 NPC，房间成为"仲裁者"。这是 Obra Dinn、Golden Idol 最强的 aha 时刻。 |
| **排除法** | "那只怕雪的狗"：三只狗，用照片和故事一只只排除。 | 从"问出答案"变成"排除错误答案"。 |
| **排时间顺序** | "Michael 出生后的第一次旅行"：要把几段故事按时间排好。 | 笔记本变成真正的推理工具。 |
| **交叉核对两个来源** | 一半信息来自她的话，一半来自物品（比如钥匙圈上的门牌号的后两位）。 | 对话和空间必须结合。 |

**退出检查**：每道新题都有链路图，通过公平性机器人和链路测试；AI 玩家的问题数落在目标区间。

### 阶段 4：重玩与长期动机（M–L）

1. **Rosie 的回忆录**：跨访问收集故事、彩蛋和人物，显示收集进度，集满一组解锁一张老照片。
2. **按难度重设 par 和星级**：用 AI 玩家实测的中位数，让 3 星真正需要高效推理。
3. **（可选）便条自动生成**：用 `chainFacts` 和现有的链路检查，从事实图里组合出新题，经过公平性机器人后进入每日题池，目标 ≥ 30 道不重复。也可以改为做第二位奶奶。

**退出检查**：每日题 30 天不重复；新题全部通过公平性机器人。

### 阶段 5：真人静默试玩（S，但最关键）

5 位没玩过的人，录屏，只观察不说话。记录：
- 解出率、问题数、用时；
- 第一次笑的地方、"aha"出现在哪一步；
- 有没有主动看房间；
- 是否想再玩一局（目标 ≥ 70%）。

**建议在阶段 1 之后马上做一轮，阶段 2–3 之后再做一轮。** 目前所有分数都来自 AI，最需要的是真人数据。

## 建议顺序

1. **阶段 1**：今天就能做，不改谜题，成本最低，Grandma 立刻更像人。
2. **阶段 5 第一轮**：拿到真人对"太简单、太单一"的确认。
3. **阶段 2 + 3**：团队批准内容后一起做，新题从一开始就按新推理方式写。
4. **阶段 4**：期末演示之后，作为作品集版本的长期内容。
