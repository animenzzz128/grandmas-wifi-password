# Paper Prototype Kit (M0)

The goal is to test whether the core loop is fun **before writing any code**. It takes about 2 hours for 4+ people.

## Roles
- **Grandma (game master):** a teammate who has read `data/grandmas/rosie.json`. They read facts aloud, in character.
- **Player:** someone who has *not* seen the facts. Ideally someone outside the team.
- **Observer:** times the session, tracks stamina, and takes notes on the sheet below.

## Setup
1. Print or open the facts list for Rosie (the `facts[].text` lines). Only Grandma sees it.
2. Write the sticky note on paper. Start with the Easy note: **"first dog's name + year I married Grandpa"** (no spaces, first letter capital).
3. Draw a teacup with 100 stamina points. Each question costs 8; long questions (> 25 words) cost +4; rude ones +6; a follow-up on the same topic costs 3 less.
4. The player gets 1 cookie (+25 stamina) and 3 password guesses.

## Rules for the Grandma player
- **Never lie.** Only say things that are in the facts.
- Answer in 1–4 sentences. If a fact answers the question, include it, **but wrap it in 1–2 other facts** (tangents).
- If the question is vague and there is a `confusable_with` pair (e.g. "what was your dog's name?"), give the **higher-salience** one: Buttons, the favorite.
- If asked for the password: "Sweetheart, if I knew it I wouldn't need a sticky note."
- Hard mode: give years only as anchor phrases ("the winter Michael broke his arm sledding").
- Stay warm and teasing. Use the verbal tics.

## What we want to learn
1. Is 100 stamina / 8 per question the right budget? (Target: Easy solved in 6–10 questions.)
2. Are the tangents funny, or annoying?
3. Do vague questions hitting confusable pairs feel fair or cheap?
4. Does the hard mode's relative-date reasoning feel clever or frustrating?
