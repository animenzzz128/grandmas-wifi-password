## Changes we made

- **Grandma** (`apps/web/src/scene/Grandma.tsx`): built at load time from the Quaternius female base and its parted hairstyle. We changed them in code: a seated pose, painted clothes (blouse, skirt, stockings, shoes), a softened chest, a puffed-out buttoned cardigan, grey hair with a bun, glasses and a crocheted lap blanket. Normal and roughness maps were dropped and the light skin texture is used. The base-color textures were resized from 2048 px PNG to 1024 px JPEG for the web (`tools/shrink-textures.py`).
- **Furniture:** scaled to fit the collider boxes in `data/scenes/rosie-living-room.json`; some are re-tinted.

## Made by us

These are built in code, so there is no third-party license to track:
- Props: bowling trophy, blue ribbon, sled, fishing rod and tackle box, cookie jar, router, sticky note, house number sign, front door, window and curtains (`apps/web/src/scene/handmade.tsx`).
- Surface textures: wood floor, wallpaper with wainscot, ceiling (`apps/web/src/scene/textures.ts`).
- Sounds: Grandma's babble voice and the UI chimes are synthesised at runtime with WebAudio (`apps/web/src/audio.ts`); there are no audio files.
- Music: the room loop "Kolaczki Rag" (8 bars, `apps/web/src/audio.ts`) was written note by note in code by Claude Code (Claude Opus 5.5, AI) under Jacky Yao's direction, 2026-11-16, and is played by the same WebAudio synth. It is AI-generated music: see the disclosure note below. Her spoken voice is either the browser's own speech-synthesis voice (`apps/web/src/voice.ts`), or, when the server is configured with a key, a voice generated by ElevenLabs (https://elevenlabs.io) from a designed voice description (`tools/design-grandma-voice.mjs`). No voice audio is bundled; generated lines are cached in `var/voice/` (git-ignored). On ElevenLabs' free plan, generated audio needs an "ElevenLabs" credit and is for non-commercial use: check their current terms before publishing.
- Grandma's lap blanket (draped cloth, `apps/web/src/scene/blanket.ts`), glasses and teacup; the spare reading glasses on the coffee table (`handmade.tsx`).
- Grandma's photos (iteration 49, `apps/web/src/scene/photos.ts`, `people.ts`): the wedding photo and the album snapshots are rendered in the game from small 3D sets built in code, then given an old-print look (`develop.ts`). The young Rosie and Walt reuse the Quaternius base body and hair listed above, with clothes, gown, veil and suit added in code; the dogs, church, porch and apartment are ours. The cards (the back of the wedding photo, the birth announcement, album pages) are drawn on canvases. Drafted by Claude Code (Claude Opus 5.5) under Jacky Yao's direction.
- The fridge and the wedding-photo frame (`apps/web/src/scene/props.tsx`). They replace the Kenney fridge and the KayKit standing frame, whose files stay in `public/models` as spares.

## Updating the art

`tools/import-assets.mjs` copies the models we use out of the unzipped packs. Run it only to add or change models; the copied files are already in the repo.

## AI-generated content

No AI-generated 3D models, textures or sound effects are used. The house and Grandma are generated by code (Blender scripts) that Claude Code drafted under Jacky Yao's direction; no image, 3D or audio generation model was involved. The room music is AI-written (see above). If that changes (for example a paid Meshy model), list it here **and** in the Steam "AI generated content" disclosure.
